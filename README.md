# Практическая работа №1
## HTML и базовая CSS-разметка. Семантическая структура страницы

Учебная информационная страница курса по технологиям веб-разработки.

## Технологии

HTML5 и CSS3. Библиотеки, JavaScript и серверная обработка не используются.

## Содержимое страницы

- Шапка с изображением и навигацией по четырём разделам.
- Описание курса и иллюстрация.
- Шесть карточек направлений из исходных данных.
- Таблица с шестью строками данных.
- Учебная форма регистрации со встроенными проверками HTML.
- Подвал с названием практической работы.

## Структура проекта

- `index.html` — разметка страницы.
- `css/styles.css` — оформление и адаптация под узкие экраны.
- `data/content.csv` — исходные данные направлений.
- `data/navigation.json` — названия пунктов навигации и идентификаторы разделов.
- `images/logo.svg` — изображение в шапке.
- `images/cover.svg` — иллюстрация в разделе «О курсе».
- `.gitignore` — исключение служебных файлов macOS из Git.

## Использование dataset

Файлы из dataset скопированы в папки `data` и `images` без изменения содержимого.

Из `content.csv` вручную перенесены данные для карточек, таблицы и списка направлений в форме. Значения `id` использованы в идентификаторах карточек и значениях вариантов выбора.

Из `navigation.json` вручную перенесены подписи ссылок и значения `target`. Каждая ссылка ведёт к соответствующему `id` раздела.

HTML не загружает CSV и JSON автоматически. При изменении исходных данных разметку нужно обновлять вручную.

Числовое поле `value` показано как «Значение», поскольку его единица измерения не указана в исходных материалах. Раздел «Расписание» содержит таблицу направлений: дат и времени занятий в dataset нет.

## Структура HTML

Использованы семантические элементы `header`, `nav`, `main`, `section`, `article` и `footer`.

Главный заголовок страницы — `h1`, заголовки разделов — `h2`, заголовки карточек — `h3`.

Таблица содержит `caption`, `thead` и `tbody`. Заголовочные ячейки связаны со столбцами и строками через `scope`.

Поля формы связаны с подписями через атрибуты `for` и `id`. Содержательные изображения имеют текстовые альтернативы `alt`.

## Приёмы CSS

- `box-sizing: border-box` для расчёта размеров.
- Контейнер с максимальной шириной 1100 пикселей.
- Flexbox для карточек, шапки и навигации.
- Перенос элементов с помощью `flex-wrap`.
- Отступы, границы и единое оформление повторяющихся элементов.
- Видимое выделение клавиатурного фокуса через `:focus-visible`.
- Ограничение ширины изображений с сохранением пропорций.
- Медиазапрос для ширины до 720 пикселей.

## Локальный запуск

1. Склонируйте репозиторий или скачайте и распакуйте его архив.
2. Откройте папку проекта.
3. Откройте `index.html` в браузере.

Устанавливать зависимости и выполнять сборку не требуется. Сохраняйте структуру папок: стили и изображения подключены относительными путями.

Во время разработки также можно открывать страницу через расширение Live Preview в VS Code.

## Работа формы

Форма демонстрирует встроенную проверку HTML:

- имя обязательно, длина — от 2 до 60 символов;
- электронная почта обязательна и проверяется на соответствие формату;
- возраст обязателен — целое число от 16 до 100 лет; диапазон выбран для учебной формы;
- направление обязательно;
- комментарий необязателен, длина — до 500 символов.

При неверном вводе браузер блокирует отправку и показывает подсказку.

При корректном вводе форма отправляется методом GET на текущую страницу. Значения попадают в адресную строку, страница открывается повторно. Реальная регистрация и сохранение заявки не реализованы.
